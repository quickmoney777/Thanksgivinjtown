# Pictures and sound

**You don't need to add any files.** Everything below was found online and
the links are saved in `content/media-cache.json`. This page is here so you
can swap any of them for a file of your own.

## How to replace one

1. Put your file in the folder shown (create it if it isn't there).
2. Add the line from the "Your own file" column to that question in the JSON.
3. Start a new game. Your file is used instead of the looked-up one.

Pictures can be `.jpg` or `.png`. Clips can be `.mp3` or `.m4a`; 20 to 30
seconds is plenty.

## Optional extras

| What | Where to put it | Why |
| --- | --- | --- |
| The full lobby song | `public/media/music/lobby.mp3` | Without it the lobby loops Apple's 30-second preview of "Here Comes the Sun" |
| A groundhog picture | `public/media/characters/groundhog.png`, then set `"image": "/media/characters/groundhog.png"` for Shadow in `content/characters.json` | There is no groundhog emoji, so Shadow is a beaver for now |

## Checking what's there

```bash
npm run media
```

lists every lookup and prints MISSING next to anything it couldn't find.
A Poster Reveal question with no picture is left out of the game; a song
question with no clip is asked as plain text instead.
